# Vitrimer Self-Healing Prediction

## Overview

This repository contains a machine learning framework for predicting the self-healing efficiency of vitrimer materials.

The framework integrates:

- Material chemistry
- Processing conditions
- Thermal properties
- Molecular descriptors
- Deep learning models

## Key Features

- Dataset construction from published literature
- Cascade representation for polymer systems
- Deep learning-based prediction

## Research Area

Computational Materials Science | Machine Learning | Vitrimers | Polymer Engineering
